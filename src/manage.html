    Where do my keys live?
    Security key
    The private key never leaves the security key. It hands back a credential ID: the private key wrapped (encrypted) with a secret only that security key has. This extension stores the credential ID and the public key in your Chrome profile, synced to your other computers if Chrome sync is on. Logging in needs both that data and the security key; neither works alone.
    Security key, discoverable credential (resident key)
    The private key is stored in one of the security key's slots. It works as above, and Import a discoverable key recovers it with the security key alone. Remove it with the security key's tools (e.g. ykman fido credentials delete).
    Passkey
    The passkey provider holds the private key, and may sync it across your devices. Anyone who can unlock the provider can use it; a security key is stronger, as its keys can't be copied.

    This extension only stores public data. Since synced data could be tampered with (e.g. through a compromised account), a key synced from another computer shows as not verified until you click Verify and confirm with its security key or passkey.
