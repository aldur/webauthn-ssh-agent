    Where do my keys live?
    Security key
    Stored: in your Chrome profile, encrypted (and synced, if Chrome sync is on). Usable: only inside that specific security key, which alone can decrypt it, so you need both.
    Security key, stored on the key (discoverable credential, or resident key)
    Stored: in one of the security key's slots. Usable: only inside that security key. Import a discoverable key adds it on another computer; remove it with the security key's own tools (e.g. ykman fido credentials delete).
    Passkey
    Stored: by your passkey provider, usually synced across your devices. Usable: by whoever can unlock the provider; a security key is stronger, as its keys can't be copied.

    In every case, this extension never holds a usable private key.

    Why verify synced keys? They come through your Google account. Whoever controls it could swap a key's public key for their own; add that to a server and they can log in. Verify checks with your security key or passkey that the public key really is theirs.
