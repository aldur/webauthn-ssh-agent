Manage keys and settings

WebAuthn SSH Agent is an SSH agent for Secure Shell that keeps your SSH keys on security keys (YubiKey, Titan, …) or passkeys. It never holds a private key, and every login needs your confirmation.

    Where do my keys live?

    Security key
    The private key never leaves the security key. When the key is created, the security key hands back a credential ID: the private key wrapped (encrypted) with a secret that only that security key has. This extension stores the credential ID and the public key in your Chrome profile, synced to your other computers if Chrome sync is on. Logging in needs both that data and the physical security key; neither works alone. If you lose the stored data, create a new key.
    Security key, discoverable credential (resident key)
    The private key is stored in one of the security key's own slots. Works as above, and on a new computer Import a discoverable key recovers it from the security key alone. Remove it with the security key's tools (e.g. ykman fido credentials delete).
    Passkey
    The passkey provider holds the private key: Google Password Manager and iCloud Keychain sync it across your devices, Windows Hello keeps it on one device. Anyone who can unlock the provider can use it. Convenient; a hardware security key is stronger because its keys can't be copied. Import works here too.

    In every case this extension stores only public data, never a private key, and sends nothing anywhere except signatures to the servers you log in to. Since synced data could be tampered with (e.g. through a compromised account), a key synced from another computer shows as not verified until you click Verify and confirm with its security key or passkey. Verify a key before adding its public key to your servers.
